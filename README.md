# 이음봉사단

마음을 잇고, 함께 만들어요! — 이음봉사단 소개 웹사이트. React + Vite로 제작된 정적 사이트입니다.

## 개발

```bash
npm install
npm run dev
```

## 빌드

```bash
npm run build
```

`dist/` 폴더에 정적 파일이 생성됩니다. Vercel 등 정적 호스팅에 그대로 배포할 수 있습니다.

## 배포 (Vercel)

1. GitHub 저장소에 push
2. [vercel.com](https://vercel.com) 에서 GitHub 저장소 Import
3. Framework Preset: **Vite** 선택 (자동 감지됨)
4. Deploy — 이후 `main` 브랜치에 push할 때마다 자동 재배포
